Vice Sunset Cover Studio — an offline, canvas-based cover art maker in the style of GTA 6 posters. Drop in your own photo (or use a built-in sample), arrange it across four multi-panel layouts, pick a sunset or neon grade, write your caption in a bold display face, and export a shareable PNG in 1080 x 1080, 1080 x 1350 or 1920 x 1080. Everything runs in the browser from local files: no uploads, no network, no Rockstar assets. The sunset sun, skyline, palms, scanlines and grain are all drawn procedurally, and the display font is Archivo Black under the SIL Open Font License.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080
