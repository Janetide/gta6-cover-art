Vice Sunset Cover Studio — an offline web app that turns any photo and a caption into GTA 6-style cover art: four multi-panel layouts, four sunset and neon colour grades, per-panel crop, pan and zoom, editable title and subtitle, and PNG export at 1080 × 1080, 1080 × 1350 and 1920 × 1080. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Drop a photo onto the cover, pick a layout and a grade, write your caption, and export a PNG. Your photos never leave your machine.
