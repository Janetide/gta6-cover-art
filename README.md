Vice Sunset Cover Studio turns your photo and a caption into striking GTA-poster-style cover art — multi-panel layouts, a Vice City sunset or neon colour grade, bold condensed lettering — and exports it as a PNG in 1080×1080, 1080×1350 or 1920×1080, entirely offline in your browser.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
